SQLITE ENGINE DEFENSE

DB-Level Immutability Trigger Lab

AuditPro guarantees compliance by enforcing immutability directly in the SQLite database engine via triggers. Even if an attacker gains raw SQL execution access or invokes rogue queries, the database engine itself aborts the query immediately.

SQL Triggers Active on db/audit.db:
CREATE TRIGGER audit_logs_prevent_update
BEFORE UPDATE ON audit_logs
BEGIN
  SELECT RAISE(ABORT, 'Audit logs are immutable: UPDATE operations are strictly prohibited by compliance policy.');
END;

CREATE TRIGGER audit_logs_prevent_delete
BEFORE DELETE ON audit_logs
BEGIN
  SELECT RAISE(ABORT, 'Audit logs are immutable: DELETE operations are strictly prohibited by compliance policy.');
END;
